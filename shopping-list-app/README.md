# Shopping List App (Список покупок v2.0) для Android

Обновлено: добавлена поддержка нескольких пользователей и возможность направлять списки покупок другому человеку!

## Новые возможности v2.0:
1. Профили пользователей: Никита, Мария, Алексей + создание новых.
2. Вкладки: «Мои списки», «Входящие», «Отправленные».
3. Прямая отправка списка любому пользователю по кнопке «Направить».
4. Облачная синхронизация между устройствами.
